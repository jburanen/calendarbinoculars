Accounts

Each account has its own Google API key, which loads the calendars listed under it. Keys only read public calendars. For each calendar, paste its iCal address, embed link, or Calendar ID.

Display

How to get a calendar link
  1. In Google Calendar, go to Settings (gear icon) → under Settings for my calendars, click the calendar.
  2. Under Access permissions for events, check Make available to public.
  3. Under Integrate calendar, copy the Public address in iCal format (or the Calendar ID) and paste it above.
How to get an API key
  1. Go to console.cloud.google.com and create or pick a project.
  2. Go to APIs & Services → Library, open Google Calendar API, and click Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key. Optionally restrict it to the Google Calendar API.

Settings are saved in this browser once an API key and at least one calendar are entered. Only all-day events are shown.
